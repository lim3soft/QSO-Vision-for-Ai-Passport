# QSO VISION 2.3

- 优化语音连续性、响度及失真控制，改善断续、爆裂和音量偏低的问题。
- 改进呼号与国家资料补全及保留，减少已识别资料再次显示未知的情况。
- 历史 QSO 最多保留 15 条，每屏五条，短按 UP/DOWN 每次滚动一条；长按调音量，双按 DOWN 静音/恢复。
- 新增可保存的 1–100% 屏幕亮度。超时菜单提供 1/5/10 分钟、Smart、Never；所有超时调暗至 1%，唤醒恢复保存亮度。
- 实时卡片改为日期时钟及右下角分段 EQ 活动动画，空闲时条形下降至零。
- 更新中英文使用说明，并在玩法介绍加入作者主页及网页版链接。

此标签包含完整当前源码；固件为作者实测的原镜像，并未重新构建。
