# QSO VISION 2.0 — historical published firmware

The exact earlier community firmware, preserved with its original digest and guide.

- Preset/custom talkgroups, Wi-Fi profiles and on-device password entry.
- Live talkgroup audio, available caller metadata and five recent QSOs.
- Historical controls: short UP/DOWN adjusts volume; hold DOWN toggles mute.
- Fullscreen menus and manual screen-off with continued audio.
- Later 2.3 improves playback/caller retention, scrolling history, brightness and the clock/EQ UI.

Flash the complete `QSO-Vision.bin` at **0x0**. Flashing can reset settings.
This is an **archive-only tag**, not a matching historical source tree. No exact
2.0 application source snapshot was retained. Prefer 2.3 for current use.
See `User-Guide-CN-EN.txt`, `manifest.json` and `SHA256SUMS.txt`.
