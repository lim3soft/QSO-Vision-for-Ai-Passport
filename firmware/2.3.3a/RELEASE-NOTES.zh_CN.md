# QSO VISION 2.3.3a

- 最近使用的 Wi-Fi 不可用时，自动寻找并连接其他可用的已保存网络，无需再次输入密码。
- 当前网络正常时保持连接；手动配网时暂停自动选择，退出设置后恢复断网重连。没有可用网络时稍后重新扫描。
- 保留已有网络及密码，避免旧设置覆盖最近使用的网络选择；失败尝试不会删除配置。
- Wi-Fi 图标改为四条清晰波纹加圆点，已连接显示绿色、未连接显示红色。

完整安装：`QSO-Vision.bin` 从 **0x0** 刷入，可能重置 Wi-Fi/设置。已有兼容 2.3.3/2.3.3a 时，使用 `QSO-Vision-APP-0x10000.bin` 从 **0x10000** 更新，不先擦除，可保留配置。两个文件均在 `SHA256SUMS.txt` 中。

构建、应用主机测试及原生 UI 预览通过。作者确认此前 Wi-Fi 恢复测试版正常；最终图标重编译包未由发布代理实机测试。完整模板检查仍有演示专用 `on_key` 检查失败，未宣称全部通过。预览为示例资料界面渲染。
