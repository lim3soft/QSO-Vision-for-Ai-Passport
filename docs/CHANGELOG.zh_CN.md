# QSO VISION 更新日志

## 2.3.3 — 2026-10-26

- 新增 256 套离线旗帜小图，显示于当前及历史呼号之前，国家文字统一大写。
- 历史加入服务提供的 BER/丢包率；缺失或待确认值显示 --，改进最终结果更新，保留真实零值。
- 历史日期改为 dd/mm/yy、时长改为 m:ss，日期、时间、时长及质量资料同一行显示。
- 恢复左下固定音量/静音状态，右侧从右向左滚动按键说明，二者互不覆盖。
- 减少重复重绘及无关话组资料处理，优化滚动说明与 EQ 活动条响应，减轻收听时的后台负载。
- 增加界面图库预览。

## 2.3 — 2026-10-25

- 优化语音连续性、响度及失真控制，改善断续、爆裂和音量偏低的问题。
- 改进呼号与国家资料补全及保留，减少已识别资料再次显示未知的情况。
- 历史 QSO 最多保留 15 条，每屏五条，短按 UP/DOWN 每次滚动一条；长按调音量，双按 DOWN 静音/恢复。
- 新增可保存的 1–100% 屏幕亮度。超时菜单提供 1/5/10 分钟、Smart、Never；所有超时调暗至 1%，唤醒恢复保存亮度。
- 实时卡片改为日期时钟及右下角分段 EQ 活动动画，空闲时条形下降至零。
- 更新中英文使用说明，并在玩法介绍加入作者主页及网页版链接。

## 2.0 — 2026-10-24（历史归档）

先前已发布固件：Wi-Fi 配置、预设/自定义组号、实时音频/呼叫者资料、五条历史及熄屏收听。保留原镜像和指南，未保留匹配的历史源码。

## 1.0 — 2026-10-24（历史归档）

最后保留的 Build: 1.0 固件。已核对布局/归档，本次未重新测试，也未保留匹配历史源码。日常使用建议 2.3。
