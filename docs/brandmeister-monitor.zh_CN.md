# 应用架构及服务集成

完整 2.3 应用源码位于 `main/`，FoloToy 硬件支持位于 `components/bsp/`。
`main/CMakeLists.txt` 列出实际应用及字体源码。保留的历史演示和上游开发文档仅供参考，
不是监听器的界面或入口。

Hoseline 音频使用观测到的 Spotter WebSocket 服务，接收 8 kHz 单声道 mu-law 流。
有界压缩队列以 20 毫秒块送往编解码器，启动保留 180 毫秒余量，采用线性语音电平
调整与峰值余量。切换组号时通过代次标记丢弃旧组排队音频。

元数据使用观测到的 BrandMeister LH v2 Socket.IO 接口，按组号过滤、SessionID
合并完成记录，最多保留 15 条，UI 只复制五条。DMR ID 可通过有界 RadioID 请求
补全；呼叫者和国家可能延迟或缺失。呼号前缀表示分配国家，不表示实际位置。
网络或 TLS 内存紧张时优先音频。

这些是观测到的网页接口，并非有可用性保证的公开音频 API。服务、资料、编解码器、
软件及商标受各权利人的条款和许可约束。应用独立开发、仅接收；当前适配器不要求
嵌入个人 BrandMeister 密钥。

UI 定时器绘制模拟活动 EQ 和本地时钟，不改变音频采样。Wi-Fi 获得 IP 后启动
网络对时，默认马来西亚 UTC+08:00。调暗仅改变背光 PWM：保存的唤醒亮度 1–100%、
自动调暗 1%、手动关屏 0%，不休眠 CPU 或重启网络/音频。没有可靠充电信号时
不开启充电动画。本版本未接入语音识别，自定义组号和密码均使用按键。

见[使用指南](USER_GUIDE.zh_CN.md)、[构建说明](BUILD.zh_CN.md)及
[验证记录](VALIDATION.zh_CN.md)。不声称已测量节电电流或完成全部网络/长期验证。
