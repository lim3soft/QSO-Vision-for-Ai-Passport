# 已保存 Wi-Fi 网络自动恢复

已纳入 **2.3.3a** 构建。作者确认此前 Wi-Fi 自动恢复测试版在 Passport 上正常。
本次增加四条波纹及连接圆点的 Wi-Fi 图标，保留绿色已连接、红色未连接状态。
音频处理、按键、显示设置及网络配置/密码存储格式保持一致。

启动先尝试最近成功使用的网络。连接失败，或原连接丢失且常规有限重试失败后，
后台服务扫描附近已保存网络。最近使用的 SSID 仍可尝试时优先，否则按信号强度
选择可见的已保存备选网络。同一 SSID 的多个 AP 只算一个配置。逐条读取所有扫描
结果，能发现排在界面前 32 条之后的已保存网络，无需额外的大型 AP 缓冲区。

每个候选配置采用有限次数重试，关联/DHCP 最长等待 30 秒。认证失败、驱动启动
失败或获取 IP 超时后继续下一候选。全部失败或没有可见网络时，30 秒后重新扫描。
失败尝试不覆盖密码、不删除配置；DHCP 成功后仅在需要时更新最近使用的 SSID。
旧格式迁移可重复安全执行，不再覆盖第零个配置或重置最近网络选择。只自动连接
已保存网络；备选网络发现需要广播 SSID。无线连接可用并不代表已能访问互联网。

正常连接时保持当前网络，即使出现更强的已保存网络也不切换。进入 Wi-Fi 列表/
密码编辑器后暂停自动选择，已联网时打开扫描仍保留连接。退出 Wi-Fi 设置后，
若断网则恢复自动寻找；手动连接已在进行时允许完成。本改动不新增任务、蓝牙服务，
正常连接时不增加后台扫描。

## 验证与实机检查

主机测试直接编译生产 Wi-Fi 管理代码，使用驱动/NVS 桩验证：双向换地点、备选
排在 35 个无关 AP 之后、最近网络优先、信号强度排序、重复 SSID、已保存开放网络、
错误密码、驱动/DHCP/扫描超时、30 秒退避、配置保留、最近网络持久化、扫描及切换
期间进入手动设置、旧格式迁移。以上验证逻辑决策，并非真实射频/DHCP 时间测量。

实机保存网络 A、B，先连接 A，再关闭 A 并保持 B 在范围内，检查自动连接 B、
About 内 SSID/IP 正确且音频恢复。重启后及反向换网再测，确认当前网络正常时不
切换、配置不丢失、恢复过程中仍可编辑密码。2.3.3a 图标及版本重编译包发布前仍需作者实机验证。
