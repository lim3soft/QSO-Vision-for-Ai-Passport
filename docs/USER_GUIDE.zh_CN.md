# QSO VISION 2.3 — 使用指南

开发者：limesoft (9W3SPY)，设备界面为英文。

QSO VISION 将 AI Passport 变成随身 BrandMeister 通话组收听器。连接互联网 Wi-Fi 后，即可通过实体按键选择通话组、收听语音，并在服务提供资料时查看当前呼号及最多 15 条历史 QSO（每屏五条）。本应用仅接收，不提供发射功能；设备界面为英文。

## 1. 快速开始

- 安装 QSO-Vision.bin 后重启。通过社区安装入口安装；手动刷写此完整固件时，起始地址为 0x0。安装可能清除已有设置，届时需重新配网。
- 主页短按 OK → Options → Wi-Fi connection，选择自己的网络并连接。
- 再从主页短按 OK → Change talkgroup，选择要收听的组。选择后自动回到监听主页。

## 2. 主要按键
监听主页：

- 短按 UP / DOWN：向较新 / 较旧历史记录滚动，每次一条。
- 长按 UP / DOWN：连续增大 / 减小音量，松开即停止。
- 双按 DOWN：静音 / 取消静音。
- 短按 OK：进入 Options 选项菜单。
- 长按 OK：屏幕渐暗熄灭，音频继续播放。
- 熄屏后再次长按 OK：屏幕渐亮唤醒；其他按键不会唤醒屏幕。
菜单页面：UP / DOWN 移动选择，短按 OK 确认，长按 OK 返回。
“双按”指快速按两次，和长按不同。

## 3. Wi-Fi 配网与密码输入

- 路径：主页短按 OK → Wi-Fi connection。等待扫描后，用 UP / DOWN 选中 SSID，短按 OK。
- 密码输入：UP / DOWN 切换字符；长按 UP / DOWN 加快滚动；短按 OK 添加当前字符；双按 UP 删除最后一个字符。
- 字符顺序：0–9、a–z、A–Z、空格及屏幕支持的特殊字符。密码最多 25 个字符，输入时明文显示，请自行核对。
- 密码输入完成后，双按 OK 开始连接。连接成功后保存配置，并自动返回监听主页。
- 无密码网络会直接开始连接。密码错误或连接失败时，长按 OK 返回列表，重新选择网络并修改密码；也可选择其他网络。
- 未发现网络时按 OK 重新扫描；退出并再次进入 Wi-Fi connection 也会重新扫描。仅打开扫描列表不会主动替换当前网络配置。
- 配网在设备上完成，无需手机或电脑辅助输入。

## 4. 已保存网络

- 在 Wi-Fi 列表选择已保存且可用的网络，按 OK，使用保存的密码连接。
- 开机时应用尝试重连上次保存的网络。离开覆盖范围的已保存网络显示 SAVED/OFFLINE。
- 修改密码：在网络列表选中该配置，双按 DOWN，编辑后双按 OK 连接。
- 删除配置：在网络列表选中已保存网络，双按 UP。注意：此操作删除网络配置；只有密码输入页面中的双按 UP 才是删除最后一个字符。

## 5. 选择通话组
路径：主页短按 OK → Change talkgroup。
预设组：91、45401、46001、46020、50210。
用 UP / DOWN 选择，短按 OK 应用并返回监听主页。
自定义组：选择 Other / Custom 后，UP / DOWN 选择数字，短按 OK 添加，双按 UP 删除最后一位，双按 OK 应用。长按 OK 取消并返回。支持的自定义组号范围为 91–16777215。

## 6. 查看状态与通联记录

- MONITORING TALK GROUP 显示当前监听组。
- 有资料时，当前呼号以橙色显示，下方为姓名、国家和时长；右下角 EQ 条形随 QSO 活动跳动，结束后下降至零（模拟活动动画）。左下角显示当前时间，格式 hh:mm:ss DAY dd/mm/yy；复用已有网络对时及马来西亚时区，同步前显示占位符。
- RECENT QSOs 从 BM 加载并保留最多 15 条已结束通话，每屏五条；短按 UP / DOWN 每次滚动一条，标题显示范围/总数。记录包括橙色呼号、青色国家，以及日期、时间和时长；通话结束后自动加入历史。切换组号后重新加载，实际条数取决于 BM 可用资料。
- Wi-Fi 图标反映无线网络连接状态；连接 Wi-Fi 不保证该网络一定可访问互联网。
- 扬声器图标绿色表示 Hoseline 已连接，红色表示未连接；静音时图标改变。绿色不代表一定有人正在通话。
- 电量高于 20% 为绿色，11–20% 为黄色，10% 及以下为红色。本版不提供实时充电检测动画。
- Options → About 可查看 SSID、信号强度、IP、子网、网关、DNS、电量及应用说明。UP / DOWN 滚动，长按 OK 返回。

## 7. 使用提示

- 无声音时，先确认未静音、音量合适、组号正确，并检查网络和 Hoseline 连接；通话组空闲时没有声音。
- 呼号、姓名、国家及历史依赖外部服务，可能延迟或不完整；并非所有通话组都有可用音频。
- 本版自定义组号使用按键输入，不提供语音识别。
- 本应用由 limesoft (9W3SPY) 独立开发，与 BrandMeister 或 Hoseline 无隶属或背书关系。相关服务、资料及商标归各自权利人所有，请按服务适用条款使用。

## 8. 屏幕亮度与超时

- 路径：主页短按 OK → Screen brightness。短按 UP / DOWN 增大 / 减小亮度 1%，长按快速调整；范围 1–100%。即时预览，按 OK 保存，长按 OK 取消未保存修改。
- 保存值用于开机、菜单、按键恢复及手动熄屏后的唤醒；正常断电重启后保留。没有保存值时默认 100%。
- Screen timeout 依次提供 After 1 / 5 / 10 minutes、Smart、Never。选择后按 OK 直接保存，不再设置独立调暗亮度。
- 所有超时模式统一渐暗到 1%。默认 Smart：监听主页无 QSO、无按键五秒后调暗，新语音或按键恢复至保存亮度；菜单保持保存亮度。定时模式按最后按键活动计时，包括通话期间。
- Never 不自动调暗。自动调暗及手动关屏都不停止音频；长按 OK 手动关屏后，来话不会点亮屏幕，仍需长按 OK 唤醒至保存亮度。
